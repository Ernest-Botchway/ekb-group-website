EKB GROUP — BUILD 02: INNOVATION & LABS

Included files:
- preview.html: open this in your browser to preview the section on its own.
- innovation-section.html: section markup to paste into your existing index.html.
- innovation.css: section styles.

INSTALL INTO THE EXISTING SITE:
1. Paste innovation-section.html into index.html, replacing the current empty Innovation section.
2. Link innovation.css in the page head, or copy its contents to the end of your existing main stylesheet.
   Example link: <link rel="stylesheet" href="css/innovation.css">
3. Do not remove or change the approved division-image styles.

This package contains the Innovation section only, not the full EKB Group website source.
